## Git
### Basics of Git
Pull - moves a repo or changes from online to your machine
Push - moves a repo or changes from your maching to online
Commit - Locally saves the snapshot of your progress and all staged changes
Add - stages changes for all files, or specific files

    Commit is a daily action
    Commits have a message that makes sense that explains what you accomplished that day
